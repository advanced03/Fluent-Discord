# Fluent Discord

A Fluent-inspired Discord theme designed to bring a Windows-like visual style to the app, with soft glassmorphism, accent-driven UI details, and polished modern styling.

This project is based on the original work by TakosThings, with a few minor bug fixes and quality-of-life improvements added on top.

## Features

- Fluent-style UI treatment inspired by Windows design language
- Custom accent color and acrylic/background options
- Refined form controls, tabs, and interface polish
- Lightweight theme customization via CSS variables

## Installation

1. Install a Discord theme loader such as BetterDiscord or Powercord.
2. Download the theme file: `Fluent-Discord-test.css`
3. Open your theme folder from the client settings.
4. Drop the CSS file into the folder and enable it in the theme list.

## Customization

The theme includes a user options section near the top of the CSS file. You can tweak values such as:

- accent hue and lightness
- acrylic background image and blur strength
- image preview scale
- other visual settings

Open the file and adjust the CSS variables under the `:root` block to match your preferences.

## Notes

The file includes comments pointing to the upstream theme wiki and options documentation, which may be useful if you want to dive deeper into configuration.
